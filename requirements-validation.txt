# ─────────────────────────────────────────────────────────────────────────────
# DroPhenix  |  requirements-validation.txt
#
# EXTRA packages needed ONLY to run validation/ and the cross-package comparison
# study. The Streamlit application itself does NOT import any of these, so they
# are deliberately kept OUT of requirements.txt — a deployment that only serves
# the app should not have to install them.
#
# Install on top of the main requirements:
#     pip install -r requirements.txt
#     pip install -r requirements-validation.txt
#
# Then:
#     python validation/run_all.py
#     python validation/comparison_study.py
#
# Every package here is an INDEPENDENT REFERENCE IMPLEMENTATION. The validation
# suite exists to check DroPhenix's own numbers against software written by
# other people, so these are not interchangeable with the modules they check.
# Where one is missing, the corresponding comparison is SKIPPED and reported as
# skipped — it is never silently treated as a pass.
# ─────────────────────────────────────────────────────────────────────────────
